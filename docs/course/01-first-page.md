# Your first page

*Module 1: The basics · about 10 minutes*

Everything in BrainWaves lives in **pages**. A page has a title and a body, and the body is made
of **blocks**: every paragraph, heading, list item, picture and table is a block. Blocks can be
moved, turned into other kinds of block, and linked to on their own.

## Learn

- **A new page:** press **Ctrl N**, click **+** next to your open tabs, or use **+** in the
  sidebar. Type the title, press **Enter**, and start writing.
- **There is no save button.** Everything is saved as you type ("All changes saved" at the
  bottom of the page).
- **The `/` menu:** type `/` at the start of a line (or anywhere) to insert any kind of block:
  headings, lists, to-dos, callouts, tables, databases and much more. Keep typing to filter it,
  for example `/tod` for a to-do. The arrow keys switch between its tabs.
- **Markdown shortcuts:** type these at the start of a line:

| Type | You get |
|---|---|
| `#`, `##`, `###` and a space | Heading 1, 2, 3 |
| `-` or `*` and a space | Bulleted list |
| `1.` and a space | Numbered list |
| `[]` and a space | To-do |
| `>` and a space | Quote |
| `!>` and a space | Callout |
| `>>` and a space | Toggle |
| three backticks | Code block |
| `---` | Divider |

- **Formatting:** select text for the formatting toolbar, or use **Ctrl B** (bold), **Ctrl I**
  (italic), **Ctrl U** (underline), **Ctrl E** (inline code).
- **Moving blocks:** point at a block and drag the **⠿** handle on its left. Click the handle for
  more: turn it into another block, duplicate it, delete it.
- **Indenting:** **Tab** and **Shift Tab** indent and outdent list items.

## Try it

- [ ] Make a new page with **Ctrl N** and call it "My first page".
- [ ] Write a heading with `## `, then a short paragraph under it.
- [ ] Make a bulleted list of three things you want to use BrainWaves for.
- [ ] Turn one of them into a to-do with `/to-do`, and tick it.
- [ ] Indent a list item with **Tab** to make a sub-item.
- [ ] Drag a block to another place with its **⠿** handle.
- [ ] Make a word **bold** and another *italic*.

> [!TIP]
> Pasting Markdown works: paste text with `#` headings, lists and tables and it becomes real
> blocks.
