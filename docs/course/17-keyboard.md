# Keyboard mastery

*Module 7: Everywhere · about 10 minutes*

Everything in BrainWaves can be done with the mouse, but the keyboard is faster. Learn a few at a
time; the right panel lists them under **Shortcuts**, and **Ctrl /** shows them all.

## Learn

| Keys | Does |
|---|---|
| **Ctrl K** | Quick find |
| **Ctrl N** | New page |
| **Ctrl Shift N** | New page from a template |
| **Ctrl W**, **Ctrl Tab** | Close tab, next tab |
| **Ctrl \\**, **Ctrl Shift \\** | Show or hide the sidebar, the right panel |
| **Ctrl /** | All the shortcuts |
| **Ctrl Shift E** | Document or canvas |
| **Ctrl Shift D** | The D&D compendium |
| **Ctrl Enter** | Fold or unfold a toggle, heading or list item |
| **Ctrl Alt 0–3** | Text, Heading 1–3 |
| **Ctrl Shift 7, 8, 9** | Numbered, bulleted, to-do list |
| **Ctrl Shift B**, **Ctrl Alt C** | Quote, code block |
| **Ctrl B, I, U, E** | Bold, italic, underline, inline code |
| **Ctrl Shift S** | Strikethrough |
| **Ctrl Z**, **Ctrl Shift Z** | Undo, redo |

> [!NOTE]
> In a browser, **Ctrl N**, **Ctrl Shift N**, **Ctrl W** and **Ctrl Tab** belong to the browser:
> no website can use them. Use **Alt** instead: **Alt N** (new page), **Alt Shift N** (from a
> template), **Alt W** (close tab), **Alt ]** and **Alt [** (next and previous tab). They work in
> the desktop app too. **Ctrl /** shows the ones that apply where you are.
| `[[`, `((`, `/`, `#` | Link a page, link a block, insert a block, a tag |

## Try it

- [ ] Write a whole page without the mouse: **Ctrl N**, a title, a heading with **Ctrl Alt 2**,
  a to-do list with **Ctrl Shift 9**, a link with `[[`.
- [ ] Jump between three pages with **Ctrl K** only.
- [ ] Hide both side panels with **Ctrl \\** and **Ctrl Shift \\** for a focused writing view,
  then bring them back.
- [ ] Pick the **Blocks** group in the right panel's Shortcuts and learn two you didn't know.
